# Agent Note: 本机编排与可重连的远端执行

Status: implemented

[English](2026-11-04-local-orchestration-remote-execution.md) | 中文

## 问题

桌面 Agent 需要操作 Linux 和原生 Windows 电脑，而不将模型凭据或对话存储移至这些电脑。SSH 中断不能终止已接纳的工作，重连也不能重复执行结果不确定的文件修改或终端输入。全局替换提供者还会影响 MCP 子进程等本机编排，而不只影响选定的会话。

## 决策

远程工作按 Agent 绑定执行服务，同时将 Agent 上下文留在本机。文件系统路由保留带电脑限定的原始项目标识；Shell 工具、搜索和浏览器终端选择已注册的执行上下文。限定会话缺少执行服务时直接失败，不回退到本机。原生命令准入依据会话的子进程环境，而非 Host 平台。

纯执行 Runtime 在远端 SSH 账户下运行，拥有托管进程、终端、有界输出和修改结果记录。SSH 只负责附加，不拥有进程。Linux 使用 `nohup` 分离；Windows 退出 OpenSSH 作业。安装前在本机完成下载和摘要校验。这与 [POSIX helper 提供者](2026-09-11-posix-ssh-runtime.zh.md)相互独立，后者按连接清理和显式部署的能力仍受支持。

### 认证权限

Host 在本机存储中保留 Ed25519 签名密钥，只上传其公开授权密钥。Runtime 在内存中生成自己的签名密钥，只将公钥公布在经已验证 SSH 读取的端点文件中。新的 nonce 和区分角色的签名在接纳大型 RPC 缓冲区前认证双方。因此，读取远端配置不授予控制权限。守护进程及其 Windows 启动器均禁用通过 `SIGUSR1` 激活 Node 调试器。

远端账户和操作系统仍属于可信范围。此设计不证明恶意主机可信，也不阻止进程内存检查。公钥端点发现依赖安装目录的写保护；不把沙箱的读取权限当作保密保护。

### 恢复所有权

观察操作等待自动重连。每次修改在发送前分配操作 ID；重连时按 ID 取回原结果，不重新提交操作。记录缺失、结果过大而无法恢复或守护进程实例不同，均报告结果未知。终端输入遵循同一规则。保留的进程字节使用偏移和有界 base64 分页，使多字节文本和二进制数据在更换传输后仍然完整，不在分页边界解码文本。

模型步骤准备等待选定电脑。显式断开暂停附加，而不停止任务。显式停止与任务期限仍拥有其权限。守护进程重启、电脑重启和新载荷代际不会重建内存任务或终端状态。

### 同版本目录准入

不可变创建 `cwd` 携带 `dsh-ssh://<computer-uuid>/<encoded-native-path>`；工作目录事件继续携带解析后的执行路径。会话类型仍为 `string`，不新增头部字段。原生 V4 编解码器独立负责执行地址准入，不依赖复用的 V2 行封装；历史 V2、V3 头部准入保持不变。

保留 V4 遵循[读取器兼容规则](../../../../docs/persistence-changes/README.zh.md#compatibility-rules)：新读取器保留所有已有原生绝对目录头部；旧读取器在头部校验时拒绝执行 URI，早于正文恢复、截断或执行。URI 是有效的拒绝信号，不是旧读取器可以忽略的可选元数据。此纯行为审查没有声明的持久化 schema 差异。已有已提交会话代际保持不变。

## 考虑过的替代方案

**在远端运行整个 Harness。** 这会将模型凭据、会话持久化和编排一起迁移到执行端，不符合本机所有权要求。

**替换全局子进程和沙箱提供者。** 本机插件进程会跟随远端文件系统和环境，使会话选择可能迁移 MCP 或其他 Host 工作。

**将工作绑定到 SSH，或重连后重放。** 按连接清理会丢失已接纳任务；自动重放可能重复编辑、启动和终端输入。稳定操作 ID 与显式结果未知保留这些区别。

**在远端配置中存储共享控制秘密。** 写入约束允许读取该文件。可读的共享秘密会让受约束代码请求不受限 Runtime 操作。公开授权密钥避免通过文件读取授予权限。

**仅为远端 cwd 提升会话格式。** 已有头部校验已能安全拒绝新地址形式，且全部既有头部含义保持不变。新增整数版本增加迁移，却没有解决其他解释问题。

## 影响

Host 拥有已保存电脑身份和附加生命周期，守护进程拥有已接纳的工作。恢复消耗有界内存，不能承诺保留全部完成记录或无限历史输出。用户在重试结果未知的操作前检查远端状态。标准和 Cordis 预设支持此组合；持久 Shell 的极简预设与 PTC 预设仍不支持远端会话。

POSIX helper 决策继续维护其独立的部署、流和租约保证。没有活动记录被完全替代。[包参考](../../../../packages/ssh/remote-work/README.zh.md)维护支持的前提与限制，而不是由本说明承载。

## 验证

[真实 Web 组合测试](../../../../apps/web/tests/remote-work.e2e.ts)只有外部模型使用脚本，执行远端文件和原生 Shell 效果，检查本机 Agent 所有权与已记录上下文，并验证安装配置不含私钥。Linux 和原生 Windows 运行同一场景。[Runtime 测试](../../../../packages/ssh/remote-work/tests/runtime.spec.ts)覆盖未授权密钥、端点身份、传输替换、字节分页、受守卫的文件操作与修改恢复。真实 SSH 中断检查还保留同一守护进程和终端环境，恢复已提交修改，并在结果被遗忘时报告未知而不重放。
